Аномалия 1: У 16% транзакций (906 шт.) отсутствует transaction_id. Рекомендация для бизнеса: проверить интеграцию с платежным шлюзом, чтобы избежать дублирования заказов в CRM.

Аномалия 2: Параметр value не заполняется в типе float_value. Рекомендация для аналитика: при построении витрины использовать double_value или рассчитывать сумму через массив товаров.
